# Lumen

Бесплатный музыкальный плеер для Windows: песни с YouTube и SoundCloud, музыка с твоего компьютера,
тексты песен, миксы под твой вкус и интерфейс «жидкое стекло».

## Как установить

1. Скачай установщик: **[Lumen-Setup.exe](https://github.com/ddrgosha228-alt/lumen-app/releases/latest/download/Lumen-Setup.exe)**
   (всегда последняя версия; все версии — на [странице релизов](https://github.com/ddrgosha228-alt/lumen-app/releases)).
2. Запусти его. Windows может показать синее окно **«Windows защитила ваш компьютер»** — это потому, что у
   программы нет платной цифровой подписи, а не потому, что она опасна. Нажми **«Подробнее» → «Выполнить в любом случае»**.
3. Выбери папку (можно оставить как есть) — Lumen поставится только для тебя, права администратора не нужны.
   На рабочем столе и в «Пуске» появится ярлык.
4. При первом запуске Lumen спросит тему, предложит перенести музыку из Spotify и добавить папку с музыкой.

Обновления приходят сами: когда выйдет новая версия, справа вверху появится кнопка **«Обновить»**.

## Если музыка не играет

- **YouTube или SoundCloud заблокированы в твоей стране.** Включи VPN. Lumen сам использует системный прокси
  и VPN-режим TUN. Если VPN работает только как прокси в браузере — открой **Настройки → Сеть**, выбери
  «Свой прокси» и впиши адрес из своего VPN-приложения (например, `http://127.0.0.1:10809`), затем нажми
  «Проверить соединение».
- **Пишет «YouTube просит подтвердить, что ты не бот» или играют только первые секунды.** Так YouTube
  отвечает, когда с одного адреса много запросов. Подожди 15 минут или смени сервер в VPN.
- **Один трек не играет, остальные — да.** Источник не отдаёт этот трек (например, он защищён) — Lumen
  попробует найти такую же песню на YouTube или пропустит её.
- **Странные старые данные, что-то не открывается.** **Настройки → Данные → «Сбросить кэш».** Лайки,
  плейлисты и скачанное останутся.

## Как сообщить об ошибке

**Настройки → Данные → «Открыть папку с логами»** — пришли файл `main.log` тому, кто дал тебе Lumen,
и опиши, что делал перед ошибкой. В файле — названия треков и тексты ошибок, без паролей; перед отправкой
его можно открыть блокнотом.

## Где хранятся данные

Медиатека, настройки и скачанное — в `%APPDATA%\Lumen`. При удалении программы они не удаляются:
переустановишь — всё на месте.
